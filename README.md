# 🍲 Hunter's Hotpot (Охотничий Котелок)

**Hunter's Hotpot** — это комплексный модуль для Foundry VTT (D&D 5e), добавляющий в игру систему свежевания монстров, кулинарии и крафта. 

## ⚙️ Как это работает (Основы интерфейса)
Модуль работает **без необходимости создавать макросы** на панели игрока (почти). Все действия встроены в интерфейс Foundry (правый клик по предмету в инвентаре):

* 🎒 **Мешок подарков** (Контейнер для лута):
  * `Котелок` — открывает окно приготовления пищи.
  * `Верстак` — открывает интерфейс ремесла.
* 🧰 **Набор свежевателя** (Инструмент):
  * `Разделать цель` — запускает сбор лута с трупа в таргете.
  * `Починить набор` — позволяет пополнить заряды набора.
* 🥩 **Любой трофей (Сырье)**:
  * `Чертежи из материала` — показывает, что можно скрафтить из этой конкретной кости или шкуры.
  * `Приготовить` — только для пригодных в пищу компонентов.

## 🗡️ Свежевание (Сбор компонентов)

Чтобы разделать монстра, охотнику требуется **Набор свежевателя** и убитая цель в таргете. 

### Условия разделки
1. **Цель мертва** (HP = 0).
2. **Цель еще не разделана** (нет эффекта "Распотрошен").
3. В Наборе свежевателя есть **достаточно зарядов**. Стоимость в зарядах и затраченное время зависят от размера существа (от 1 заряда для Крошечного до огромных затрат на Колоссального).

### Механика броска
Базовый навык и характеристика для разделки — **Выживание (Ловкость)**. Однако модуль учитывает тип существа и предлагает альтернативы:
* **Грубая разделка (Сила):** для Конструктов, Растений, Великанов.
* **Ритуальное свежевание (Инт/Муд/Хар):** для Аберраций, Небожителей, Элементалей, Фей, Исчадий.

Охотник может привлечь **помощников** (дружественные токены рядом). Чем больше тело, тем больше помощников можно привлечь. Помощники с владением нужным навыком дают бонус `+ БМ`, без владения `+ (БМ / 2)`.

### Эссенции (Редкий лут)
Если финальный бросок достаточно высок (СЛ зависит от CR существа), охотник может добыть **Эссенцию**. Это концентрированная магия существа, которая дает мощнейшие эффекты при готовке и крафте.
* CR 3–6: *Слабая Эссенция* (СЛ 25)
* CR 7–11: *Грубая Эссенция* (СЛ 30)
* CR 12–17: *Мощная Эссенция* (СЛ 35)
* CR 18–24: *Мифическая Эссенция* (СЛ 40)
* CR 25+: *Божественная Эссенция* (СЛ 50)

## Набор свежевателя
Механизм изначального получения Набора свежевателя отсутствует. Набор появляется при использовании макроса `Ремонт Набора свежевателя`.

### Ремонт Набора свежевателя
Свежевание изнашивает инструменты и тратит консерванты. Игрок может починить Набор, используя опцию `Починить набор`. 
* Для починки используются материалы (например, кожа для ремней, жидкости для смазки и консервации).
* Каждое восстановление требует затрат компонентов по весу. Коэффициент затрат настраивается.
* Изначально Набор свежевателя содержит 10 зарядов. При починке уже целого набора запас зарядов увеличивается.

## 🔨 Ремесло

### Создание экипировки (WIP)
Игроки могут создавать предметы из добытых материалов. Для этого:
1. Вызовите контекстное меню на любом материале в инвентаре (например, "Чешуя Красного Дракона").
2. Выберите `Чертежи из материала`.
3. Модуль покажет список рецептов брони или оружия, которые можно сделать из этого типа сырья.
4. Выберите рецепт — откроется окно Верстака со списком используемых для рецепта компонентов

Для предметов необычной редкости и выше требуется соответствующая эссенция. Суммарная стоимость выбранных компонентов должна соответствовать редкости предмета.

![alt text](image-3.png) ![alt text](image-5.png)

После начала проекта в инвентаре появляется Заготовка предмета.
В контекстном меню при выборе пункта `Продолжить работу` открывается окно работы.
По завершению работы в инвентаре появляется болванка созданного предмета. Модуль не предоставляет магические предметы и не завязывается на конкретные компендиумы. Выберите любую реализацию и используйте ее.

Причуды магических предметов несут более косметический характер, чтобы не влиять на баланс.

| Название              | Описание                                                                                                              |
| --------------------- | --------------------------------------------------------------------------------------------------------------------- |
| Иллюзорная гравировка | На предмете мерцает руна. Можно использовать фокус «Чудотворство» для создания искр или тихого звука вокруг предмета. |
| Всегда чистый         | Материал отталкивает грязь и кровь. Предмет всегда выглядит так, будто его только что отполировали.                   |
| Комфортный            | Предмет приятно холодит в жару и согревает в мороз.                                                                   |
| Светоч                | По желанию владельца предмет испускает тусклое свечение (цвета эссенции) в радиусе 5 футов.                           |
| Эхо создания          | При извлечении оружия или надевании брони раздается тихий, приятный звук (звон, гул или шепот ветра).                 |

| Название         | Описание                                                                                                          |
|------------------|-------------------------------------------------------------------------------------------------------------------|
| Разговорчивый    | Иногда предмет издает тихие неуместные звуки (вздох, кряканье, странный скрип), когда вы его достаете.            |
| Мерзкая текстура | Визуально предмет нормальный, но на ощупь кажется склизким, слишком теплым или покрытым микро-мурашками.          |
| Пачкающий        | Предмет оставляет слабые цветные следы (сажа, пыльца, блестки) на руках и одежде. Легко смывается, но раздражает. |
| Резкий запах     | От предмета пахнет мокрой псиной, серой или тиной в радиусе 5 футов.                                              |
| Обидчивый        | Если вы выбрасываете «1» на кубике, предмет тускнеет и выглядит непрезентабельно до следующего отдыха.            |
